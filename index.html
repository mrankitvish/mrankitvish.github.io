Desktop AI / agents

02

Gnome Agent

A local-first AI assistant inside the GNOME desktop. Combines multi-provider LLM support, MCP tools, streaming responses, and persistent conversations.

  • LangGraph
  • FastAPI
  • MCP
  • SQLite
Explore Gnome Agent
Implementation notes

A GNOME Shell extension connects to FastAPI over HTTP and server-sent events. LangGraph handles agent execution; SQLite checkpoints preserve conversation state across restarts. MCP connects desktop and filesystem tools.

Retrieval / conversational AI

03

RAG Chatbot

Chat with your own text and CSV data. A retrieval-augmented API that combines local Ollama models, Hugging Face embeddings, and PostgreSQL vector search.

  • LangChain
  • Ollama
  • pgvector
  • FastAPI
Explore RAG Chatbot
Implementation notes

Separate API endpoints initialize the vector store from text or CSV and handle chat queries. LangChain connects retrieval to an Ollama-hosted language model, with conversation history management.

Local inference / model serving

04

OpenVINO API Server

Local LLM inference through an OpenAI-compatible API. Uses Intel OpenVINO to serve chat completions with familiar request formats and streaming support.

  • OpenVINO
  • Python
  • FastAPI
  • OpenAI API
Explore OpenVINO Server
Implementation notes

Exposes /v1/chat/completions, /v1/models, and /health. Supports configurable sampling, token limits, and server-sent event streaming with locally stored OpenVINO model and tokenizer files.

AI-assisted infrastructure

05

Kubectl AI Agent

Translate natural language into Kubernetes commands. Separates command generation from optional execution, with validation, caching, rate limiting, and metrics.

  • Kubernetes
  • LangChain
  • FastAPI
  • Prometheus
Explore Kubectl AI Agent
Implementation notes

Distinct /kubectl-command and /execute endpoints keep generation and execution separate. The service includes API-key authentication, TTL caching, rate limiting, and Prometheus-compatible instrumentation.
